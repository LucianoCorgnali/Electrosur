# ElectroSur

Landing comercial para empresas con flotas, desarrollada con React y Vite.

## Estructura

```text
src/
├── app/            # Composición general de la aplicación
├── components/
│   ├── layout/     # Header y footer
│   └── ui/         # Piezas reutilizables
├── data/           # Contenido y datos editables
├── sections/       # Secciones comerciales de la landing
├── utils/          # Funciones sin interfaz
├── main.jsx
└── styles.css
```

La estructura está organizada por responsabilidad, sin crear una carpeta por cada elemento pequeño.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```
